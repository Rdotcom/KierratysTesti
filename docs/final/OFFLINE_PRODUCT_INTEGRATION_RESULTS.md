## What actually runs

Existing photo screen → metadata-clean transient JPEG → native barcode/full+ROI
OCR/real MobileCLIP-S0 full-frame vector → validated local catalogue → source
record / confirmation suggestion / absent code / unknown. Manual entry uses the
same catalogue offline. Camera/model unavailable and cancel/background/old-client
recovery remain explicit. Material recognition remains a separate action; sorting
still requires the existing component/material/rule flow. No name-to-bin inference.

Five actual OFF records,10real reference vectors,134619formatted bytes. Internal
product IDs differ from GTINs; missing manufacturer/variant/market/packaging
attributes are null. Source mapping is not verified physical identity.

asset, not an implemented network catalogue update or SQLite persistence layer.
